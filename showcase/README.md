# Showcase

Pictures of the five iPhone apps for display (portfolio, website, sharing). Every screen shows the apps' made-up sample data (their DEBUG sample mode): no real account, transaction, listing or note.

Made by `scripts/showcase.py`, which also writes this file; change a shot or caption in its `SHOTS` table.

## Make them again

```
python3 scripts/showcase.py               # all five apps
python3 scripts/showcase.py empire        # one app (or several)
```

Needs the Mac with Xcode 27 and the iOS 27.0 simulator runtime, Python 3 with Pillow, and pngquant (`brew install pngquant`). All five apps take about 6 minutes: building, starting the simulator, then about 8 seconds per shot. The script builds the named apps into `build/showcase/` (git-ignored), makes its own simulator `claude-showcase` (iPhone 17) and deletes it at the end, so no other simulator is touched. It launches each app once per shot with its sample arguments in English, draws an iPhone around the screenshot (drawn by the script, no Apple artwork) and replaces that app's images here. A contact sheet of all images goes to `build/showcase/contact-sheet.png`.
